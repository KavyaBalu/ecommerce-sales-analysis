# E-Commerce Sales Analysis Using Excel

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to identify sales trends, compare city and sales-channel performance, and summarize key business metrics.

## Business Objectives
- Calculate total net sales and order count.
- Compare sales performance across cities.
- Compare Online and Store sales.
- Analyze product categories.
- Use Excel formulas and PivotTables to generate business insights.

## Tools Used
- Microsoft Excel
- Excel formulas: `IF`, `SUMIF`, `SUMIFS`, `COUNTIF`, `COUNTIFS`, `IFS`, `IFERROR`, `AND`, and `OR`
- PivotTables and PivotCharts
- Data cleaning and validation

## Key Findings
- **Total net sales:** ₹113,030.50
- **Total orders:** 40
- **Top city by net sales:** Kochi — ₹28,571.40
- **Top category by net sales:** Home
- **Online sales:** ₹64,408.75
- **Store sales:** ₹48,621.75

Online sales exceed Store sales in this dataset.

## Project Files
- `data/ecommerce_sales.csv` — source dataset
- `excel/ecommerce_sales_analysis.xlsx` — Excel analysis and dashboard

## Skills Demonstrated
Data analysis, spreadsheet formulas, data validation, PivotTables, PivotCharts, KPI reporting, and business insight communication.

## Note
This project uses a sample dataset created for learning and portfolio demonstration. The findings describe this dataset and should not be interpreted as real company sales.
